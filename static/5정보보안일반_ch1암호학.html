암호 알고리즘

기출 1
핵심 용어
Diffie-Hellman 키 교환
기출문제교재에 단답·서술 구분 없음 · 직접 써 보고 답과 비교
Q13회

다음은 Diffie-Hellman 알고리즘을 통한 키 교환 과정이다. 빈칸에 알맞은 식을 쓰시오.

  1. Alice가 소수 p를 선택하고, p보다 작은 정수 g를 선택한다.
  2. Alice가 정수 a를 선택하고, Alice가 공개키 ( ① )을/를 계산한다.
  3. Bob이 정수 b를 선택하고, Bob이 공개키 ( ② )을/를 계산한다.
  4. Alice와 Bob이 서로에게 ( ① ), ( ② )을/를 전송한다.
  5. Alice와 Bob은 ( ① ), ( ② )을/를 이용해 공유키인 ( ③ )을/를 가지게 된다.
답과 해설 보기
답

① ga mod p　② gb mod p　③ gab mod p

해설
  • Alice와 Bob은 gab mod p 값을 공유키로 가짐
  1. 소수, 원시근 선택 (Alice)소수 p를 선택 / 원시근(Primitive Root)를 선택하는데, g는 p보다 작아야 함
  2. 개인키 생성 (Alice)개인키 a를 생성 / g, p, a를 이용해 공개키 A값을 계산A = ga mod p
  3. 공개키 전송 (Alice → Bob)g, p, 공개키 A를 전달 / Alice는 g, p, a, A 값을 가지고 있음 / Bob은 g, p, A 값을 가지고 있음
  4. 개인키 생성 (Bob)개인키 b를 생성 / g, p, b를 이용해 B값을 계산B = gb mod p
  5. 공개키 전송 (Bob → Alice)공개키 B를 전달 / Alice는 g, p, a, A, B 값을 가지고 있음 / Bob은 g, p, b, A, B 값을 가지고 있음
  6. 공유키 생성 (Alice)Alice는 Ba mod p라는 공유키를 가짐Ba mod p = (gb)a mod p = gab mod p
  7. 공유키 생성 (Bob)Bob은 Ab mod p라는 공유키를 가짐Ab mod p = (ga)b mod p = gab mod p

Q117회

공격자가 Mimikatz와 같은 도구를 활용하여 시스템 메모리에서 사용자 비밀번호의 NTLM 또는 LanMan 해시 값을 획득하고, 이 해시값 자체를 이용하여 원격 서버나 서비스에 인증을 시도하는 해킹 기법은 무엇인지 쓰시오.

답과 해설 보기

답: Pass-the-Hash 공격

  • Pass-the-Hash 공격은 사용자 비밀번호 자체가 아닌 비밀번호의 해시값을 사용하여 원격 서버나 서비스에 대한 인증을 통과하는 해킹 기법
  • Pass-the-Hash 공격은 공격자가 Mimikatz와 같은 도구를 활용하여 시스템 메모리에서 사용자 비밀번호의 NTLM 또는 LanMan 해시 값을 획득하고, 이 해시값 자체를 이용하여 원격 서버나 서비스에 인증을 시도하는 해킹 기법
  • Pass-the-Hash 공격의 대응 방법
    • 해시값 노출 금지 — 패스워드 해시값을 외부로 노출하지 않아야 함
    • 안전한 프로토콜 사용 — NTLM 프로토콜보다는 Kerberos 프로토콜을 사용하는 것이 안전
