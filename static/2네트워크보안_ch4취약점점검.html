Q12회

다음은 라우터를 활용한 네트워크 보안 기능과 관련된 내용이다. 괄호 (　) 안에 들어갈 용어를 쓰시오.

  • ( ① )은/는 내부 네트워크로 유입되는 패킷 중 유효하지 않거나 악의적인 IP 주소를 가진 패킷을 차단하는 필터링 방법이다.
  • ( ② )은/는 내부(자신의 네트워크)에서 외부(Internet 또는 다른 네트워크)로 나가는 패킷을 필터링하는 방법이다.
  • ( ③ )은/는 특정 트래픽(특정 목적지나 출발지 IP주소 및 포트 등)을 의도적으로 '없는 경로(null interface)'로 라우팅하여 패킷을 폐기하는 방법이다.
답과 해설 보기

답: ① Ingress 필터링　② Egress 필터링　③ Blackhole 필터링(Null Routing)

  • Ingress 필터링
    • 외부(Internet 또는 다른 네트워크)에서 내부(자신의 네트워크)로 들어오는 패킷을 필터링하는 방법
    • Ingress(들어오는 방향) 필터링을 통해 내부 네트워크로 유입되는 패킷 중 유효하지 않거나 악의적인 IP 주소를 가진 패킷을 차단
  • Egress 필터링
    • 내부(자신의 네트워크)에서 외부(Internet 또는 다른 네트워크)로 나가는 패킷을 필터링하는 방법
    • Egress(나가는 방향) 필터링을 통해 내부 네트워크에서 나가는 패킷 중 위조된 IP주소나 허용되지 않은 프로토콜, 포트를 사용하는 패킷을 차단
  • Blackhole 필터링 (NULL ROUTING)
    • 특정 트래픽(특정 목적지나 출발지 IP주소 및 포트 등)을 의도적으로 '없는 경로(null interface)'로 라우팅하여 폐기(드롭)하는 방법
    • 보통 라우터나 방화벽에서 특정 IP 또는 도메인을 null-route로 지정해서 해당 패킷을 즉시 폐기하는 방법

Q428회

다음은 VLAN에 대한 설명이다. 괄호 (　) 안에 들어갈 용어 및 명령어를 쓰시오.

( ① )은/는 관리자가 직접 모든 포트에 VLAN 관련 정보를 설정하는 방식으로 일반적으로 가장 많이 사용하는 방식이다.
( ② )은/는 VLAN이 관리 서버의 정책에 따라 동적으로 자동 할당된다.
이 때 CISCO 스위치에서 VLAN 확인 명령어는 ( ③ )이다.
답과 해설 보기

답: ① 정적 VLAN　② 동적 VLAN　③ show vlan

VLAN의 종류
  • 정적 VLAN (포트 기반 VLAN)
    • 1계층 물리 계층에서 스위치 포트 단위로 VLAN을 구성하는 방식
    • VLAN 할당을 관리자가 직접 포트에 VLAN 관련 정보를 설정
    • 일반적으로 가장 많이 사용하는 방식
  • 동적 VLAN (MAC 기반 VLAN)
    • 2계층 데이터 링크 계층에서 MAC 주소를 기반으로 VLAN을 구성하는 방식
    • VLAN 할당이 동적으로 자동화 할당(관리 서버로부터 할당)
  • IP 기반 VLAN — 3계층 네트워크 계층에서 IP 주소를 이용하여 VLAN을 구성하는 방식
  • 프로토콜 기반 VLAN — 같은 통신 프로토콜끼리만 통신할 수 있도록 VLAN을 구성하는 방식

Q220회

Smurf 공격을 방지하기 위하여, FastEthernet0/0 인터페이스를 통해 신뢰할 수 있는 네트워크 범위(192.168.1.0/24)를 사칭한 유입되는 ICMP 패킷을 차단하고, 브로드캐스트 변환을 막는 보안 설정을 하려고 한다. 이때 밑줄친 곳에 들어갈 라우터 명령어를 쓰시오.

Router(config)# ① Router(config)# access-list 100 permit ip any any Router(config)# ② Router(config-if)# ip access-group 100 in Router(config-if)# no ③
모범 답안과 해설 보기
모범 답안

① access-list 100 deny icmp 192.168.1.0 0.0.0.255 any

② interface FastEthernet0/0

③ ip directed-broadcast

  • access-list 100 deny icmp 192.168.1.0 0.0.0.255 any — 출발지 IP가 192.168.1.0~192.168.1.255로 설정된 모든 ICMP 패킷이 어떤 목적지로 향하든지 간에 차단되도록 하는 100번 ACL 규칙이다.
  • access-list 100 permit ip any any — 출발지 IP가 192.168.1.0~192.168.1.255로 설정된 ICMP 패킷을 제외한 트래픽은 허용한다.
  • interface FastEthernet0/0 — FastEthernet0/0 인터페이스의 설정 모드로 진입한다.
  • ip access-group 100 in — FastEthernet0/0 인터페이스로 유입되는 트래픽에 대해 100번 ACL 규칙을 적용한다.
  • no ip directed-broadcast — Directed Broadcast 기능을 비활성화시킨다.

보안장비 주요 계정관리 점검 항목
  • 방화벽, IPS, VPN, IDS, Anti-DDoS, 웹 방화벽 등과 같은 보안장비의 취약점 점검 항목 중 주요 계정관리는 다음과 같음
  • 보안장비 Default 계정 변경 — 보안장비에 기본적으로 설정되어 있는 관리자 계정의 변경 여부 점검
  • 보안장비 Default 패스워드 변경 — 보안장비에 기본적으로 설정되어 있는 관리자 계정의 패스워드를 변경 없이 사용하고 있는지 점검
  • 보안장비 계정별 권한 설정 — 보안장비에 등록한 계정들에 대해 업무에 불필요한 권한 여부 점검
  • 보안장비 계정 관리 — 보안장비에 등록되어 있는 계정 중 사용하지 않는 계정을 제거 또는 관리하고 있는지 점검
