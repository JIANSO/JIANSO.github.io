Q11회

다음 괄호 (　) 안에 알맞은 용어를 쓰시오.

SNMP Manager는 ( ① ) 방식으로 네트워크 장비의 상태 정보 및 통계정보를 주기적으로 수집하며, SNMP Agent는 ( ② ) 방식으로 장비의 특정 이벤트를 실시간으로 SNMP Manager로 전달하여 장비의 상태 변경을 알려준다. 그리고 ( ③ ) 방식은 장비에서 일어나는 모든 상황 혹은 변화를 서버에 기록하는 프로토콜로 어떤 이벤트가 발생하면 즉시, 이벤트를 자신의 로그 파일로 저장하는 동시에 ( ③ ) 서버로 전송한다.
답과 해설 보기

답: ① 폴링(Polling)　② 이벤트 리포팅(Event Reporting)　③ Syslog

SNMP의 데이터 수집 방식
  • 폴링(Polling) 방식
    • Manager가 Agent에게 정보를 요청하면 응답해주는 방식
    • Agent가 161번 포트를 사용
  • 이벤트 리포팅(Event Reporting) 방식
    • Agent가 이벤트 발생 시 이를 Manager에게 알리는 방식
    • Manager가 162번 포트를 사용
  • SNMP Agent는 UDP 161번 포트, SNMP Manager는 UDP 162번 포트를 사용
Syslog
  • 장비에서 일어나는 모든 상황 혹은 변화를 서버에 기록하는 프로토콜
  • 어떤 이벤트가 발생하면 즉시, 이벤트를 자신의 로그 파일로 저장하는 동시에 Syslog 서버로 전송

답: OPTIONS

HTTP 요청(Request) 시작 라인의 구조
  • HTTP Method — 요청 시 보내는 HTTP 메서드 형태 (GET, POST, PUT, DELETE, TRACE 등)
    • GET
      • 어떠한 데이터를 받아올 때 주로 사용하는 메서드
      • GET일 때 본문(Body)이 없는 경우가 많음
    • POST
      • 데이터를 생성/수정/삭제할 때 주로 사용되는 메서드
      • 요청 파라미터를 본문(Body)에 붙여서 전송하며, 전송할 데이터의 양이 많은 경우 또는 민감 정보를 전송해야 할 때 주로 사용
    • OPTIONS
      • 서버가 해당 경로에 대해 지원하는 메서드를 물어볼 때 사용하는 메서드
      • OPTIONS / HTTP/1.1 → 해당 경로(/)에 지원하는 메서드를 물어보면 HTTP 응답 헤더의 Allow 항목에서 나타남
  • Request Target — 어디로 보내는지에 대한 URI
  • HTTP Version — 사용하고 있는 HTTP 버전
HTTP 응답(Response) 헤더
  • Allow — 서버가 요청한 경로에 대해 허용하는 HTTP 메서드를 나타내는 부분 Allow: GET, HEAD, POST, OPTIONS → OPTIONS / HTTP/1.1과 같이 해당 경로(/)에 지원하는 메서드를 OPTIONS로 물어봤을 때, Allow로 허용하는 HTTP 메서드를 나타냄
  • HTTP 요청에서 OPTIONS 메서드를 이용하여 요청했을 경우, HTTP 응답 헤더의 Allow 항목을 통해 허용하는 메서드를 나타냄

Q611회

다음은 SNMP(Simple Network Management Protocol)에 대한 설명이다. 괄호 (　) 안에 들어갈 올바른 숫자 및 용어를 쓰시오.

SNMP는 IP 네트워크상의 장치로부터 정보를 수집·관리하고, 필요 시 설정을 변경하는 데 사용되는 인터넷 표준 프로토콜이다. Polling 방식은 Manager가 Agent에게 정보를 요청하며, Agent는 UDP ( ① )번 포트에서 이를 수신하여 응답한다. ( ② ) 방식은 Agent가 이벤트 발생 시 Manager에게 Trap 메시지를 전송하며, Manager는 UDP ( ③ )번 포트에서 이를 수신한다.
답과 해설 보기

답: ① 161　② 이벤트 리포팅(Event Reporting)　③ 162

SNMP의 데이터 수집 방식
  • 폴링(Polling) 방식
    • Manager가 Agent에게 정보를 요청하면 응답해 주는 방식
    • Agent가 161번 포트를 사용
  • 이벤트 리포팅(Event Reporting) 방식
    • Agent가 이벤트 발생 시 이를 Manager에게 알리는 방식
    • Manager가 162번 포트를 사용
Q722회

다음은 라우팅 프로토콜에 대한 설명이다. 괄호 (　) 안에 들어갈 프로토콜을 쓰시오.

  • ( ① )은/는 AS 내에서 사용하는 거리 벡터 알고리즘에 기초하여 개발된 내부 라우팅 프로토콜로 홉 수를 최적 경로를 결정하기 위한 메트릭 정보로 이용하며 최대 홉 수(Hop Count)를 15개로 제한한다.
  • ( ② )은/는 규모가 크고 복잡한 TCP/IP 네트워크에서 RIP의 단점을 개선하기 위해 자신을 기준으로 링크 상태 알고리즘을 적용하여 최단 경로를 찾는 라우팅 프로토콜이다.
  • ( ③ )은/는 시스코사가 만든 원래의 IGRP를 기반으로 한 개방형 라우팅 프로토콜로 Metric 요소는 대역폭, 지연, 신뢰도, 부하, 최대 전송 단위, 홉 카운트가 있다.
답과 해설 보기
  • ① RIP(Routing Information Protocol)
  • ② OSPF(Open Shortest Path First)
  • ③ EIGRP(Enhanced Interior Gateway Routing Protocol)
라우팅 프로토콜의 종류
  • RIP (Routing Information Protocol)
    • AS 내에서 사용하는 거리 벡터 알고리즘에 기초하여 개발된 내부 라우팅 프로토콜
    • 홉 수를 최적 경로를 결정하기 위한 메트릭 정보로 이용하며 최대 홉 수를 15개로 제한
    • RIPv1은 CIDR 기법이 적용되어 있지 않고, RIPv2부터 CIDR 기법이 적용되어 있음
  • OSPF (Open Shortest Path First) — 규모가 크고 복잡한 TCP/IP 네트워크에서 RIP의 단점을 개선하기 위해 자신을 기준으로 링크 상태 알고리즘을 적용하여 최단 경로를 찾는 라우팅 프로토콜
  • BGP (Border Gateway Protocol) — AS 상호 간(Inter-AS 또는 Inter-Domain)에 경로 정보를 교환하기 위한 라우팅 프로토콜
  • EIGRP (Enhanced Interior Gateway Routing Protocol)
    • 시스코사가 만든 원래의 IGRP를 기반으로 한 개방형 라우팅 프로토콜
    • EIGRP Metric 요소는 대역폭, 지연, 신뢰도, 부하, 최대 전송 단위, 홉 카운트가 있음

무선 네트워크에서는 충돌을 회피하기 위하여 CSMA/CA 프로토콜을 사용한다. 이 경우, 타임아웃 설정은 어느 신호에 포함되는지 [보기]에서 2개를 선택하여 쓰시오.

[보기]　SYN, ACK, RTS, CTS, DATA, RST
답과 해설 보기

답: ① RTS　② CTS

  • CSMA/CA 방식은 무선 네트워크에서 충돌 발생을 방지하기 위해 전송 전에 채널 상태를 확인하고, 충돌을 회피하는 방식으로 동작하는 매체 접근 제어 기법
  • RTS와 CTS 신호는 주변 모든 호스트에게 전송되어, 이를 받은 호스트들은 지정된 시간 동안 통신을 피하려고 타임아웃 시간 동안 NAV 모드에 들어감
  • NAV 모드는 RTS/CTS 프레임에 포함된 채널 사용 시간 정보를 근거로, 주변 기기들이 해당 시간 동안 통신을 중단하고 대기하도록 설정하는 가상의 타이머 기능
RTS · CTS
  • RTS (Request To Send)
    • 송신 측이 수신 측에게 데이터를 전송할 의사가 있음을 알리는 신호
    • 타임아웃 정보를 포함
  • CTS (Clear To Send)
    • 수신 측이 송신 측에게 데이터를 받을 준비가 되어 있음을 알리는 신호
    • 타임아웃 정보를 포함
